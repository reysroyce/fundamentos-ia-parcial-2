Reconocimiento inteligente de dígitos

Sistema demostrativo que transforma una imagen de 28 × 28 píxeles en características numéricas, compara esas características mediante un grafo de búsqueda y ajusta sus pesos con un algoritmo genético.

1. Formulación del problema de búsqueda

El objetivo es asignar a una imagen de entrada una etiqueta entre los dígitos 0, 1, 2, …, 9. El sistema representa la imagen mediante rasgos visuales y busca el dígito cuya representación sea más similar.

Estado inicialImagen de 28 × 28 píxeles convertida a escala de grises y normalizada en un vector de 784 valores.
EstadosInterpretaciones parciales: imagen normalizada, rasgos extraídos y candidatos de clasificación (0–9).
AccionesExtraer rasgos, calcular similitudes, expandir un nodo vecino y actualizar el mejor candidato.
Prueba objetivoSe alcanza cuando el nodo candidato es el dígito esperado o cuando la distancia al patrón candidato es menor que el umbral definido.

Función de coste

Se utiliza una distancia ponderada entre el vector de rasgos de la imagen y el prototipo de cada dígito:

C(x,d) = Σᵢ wᵢ · | fᵢ(x) − pᵢ(d) |

Donde fᵢ(x) es el rasgo extraído de la imagen, pᵢ(d) es el rasgo del prototipo del dígito y wᵢ es el peso optimizado. Un coste menor representa mayor similitud.

Justificación de la búsqueda

Se modela como búsqueda porque existen varios estados candidatos y se debe seleccionar el que minimiza el coste. A* utiliza una heurística basada en la distancia estimada restante; BFS y DFS permiten comparar estrategias de recorrido sin utilizar información adicional del coste.

2. Grafo representativo

El grafo contiene un nodo inicial Unknown y diez nodos objetivo (0–9). Las aristas conectan el nodo inicial con cada candidato; su peso es el coste de similitud calculado con los rasgos. También se conectan los candidatos entre sí según similitud para visualizar relaciones.

3. Funcionamiento de los algoritmos

BFS — búsqueda en anchura

Explora primero todos los vecinos del nodo actual y después avanza por niveles. Utiliza una cola FIFO. Es completa en grafos finitos, pero no considera los pesos; por ello no garantiza el camino de menor coste en un grafo ponderado.

DFS — búsqueda en profundidad

Avanza por una rama hasta que no puede continuar y después retrocede. Utiliza una pila (o recursión). Consume poca memoria, pero puede recorrer una rama poco conveniente y no garantiza el camino óptimo.

A* — búsqueda informada

Selecciona el nodo con menor f(n) = g(n) + h(n). g(n) es el coste acumulado y h(n) estima el coste restante. Aquí la heurística usa la distancia de rasgos al candidato objetivo. Con una heurística admisible, A* encuentra una solución óptima.

Algoritmo genético

Cada cromosoma es un vector de pesos para los rasgos. El fitness mide el porcentaje de aciertos en un conjunto de validación simulado. Se seleccionan los mejores, se cruzan y se mutan; el proceso se repite hasta alcanzar el límite de generaciones o una mejora suficiente.

Flujo del sistema

Imagen 28×28 → normalización → extracción de rasgos
       → cálculo de similitud → construcción del grafo
       → BFS / DFS / A* → candidato reconocido
       → algoritmo genético ajusta los pesos → evaluación

Operadores genéticos: selección por torneo, cruce de un punto y mutación aleatoria pequeña. Criterio de parada: 35 generaciones o fitness ≥ 95 % en la validación simulada.

Sube una imagen de un solo dígito. El sistema la adapta a 28 × 28, extrae características, actualiza el grafo y compara los diez candidatos. También puedes dibujar directamente en el recuadro.
